# 💈 System Barber - Agendamento Barbearia

Este repositório contém um sistema de agendamento em Java desenvolvido com o objetivo de **praticar e consolidar meus conhecimentos na linguagem Java** e nos conceitos de Programação Orientada a Objetos (POO).

## 🎯 Objetivo de Estudo
O projeto foi desenvolvido para praticar:
- **Programação Orientada a Objetos (POO):** Classes, objetos, métodos e encapsulamento.
- **Arquitetura de Código:** Separação de responsabilidades em pacotes (`entities`, `services`, `application`).
- **Estruturas de Dados:** Manipulação de listas com `ArrayList`.
- **Manipulação de Datas:** Uso de `LocalDateTime` e `DateTimeFormatter` para validação de horários.
- **Lógica e Interatividade:** Leitura de dados pelo terminal (`Scanner`) e tratamento de opções do menu.

## 🛠️ Tecnologias
- Java 21
- Git / GitHub
